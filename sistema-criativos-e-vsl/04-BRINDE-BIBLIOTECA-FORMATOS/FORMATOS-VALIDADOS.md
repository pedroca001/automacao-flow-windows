# ✅ FORMATOS VALIDADOS — o que já foi reproduzido com sucesso (e o que quebrou)

> **"Validado" aqui tem um significado preciso:** o formato foi reproduzido 100% correto em produção real com IA — exemplo pronto + receita de montagem dominada. **Não significa "vendeu"** (venda é métrica de criativo individual, medida em campanha). Significa: se você mandar produzir este formato pelo pipeline, ele SAI CERTO, sem surpresa.
>
> Essa separação importa: formato validado entra em produção de volume SEM supervisão cena a cena — você confere só o resultado final. Formato não-validado entra 1-2 por leva, com gate de frames no meio.

## PARTE 3 — A PRATELEIRA DOS QUE FALHARAM (ensina pelo erro)

Formatos que REPROVARAM no gate de reprodução IA. Não significa que o formato é ruim no mercado — significa que a produção IA dele tem bugs conhecidos. Se for tentar, saiba onde dói:

| Formato | O bug que derrubou |
|---|---|
| **Diálogo (2+ personagens)** | gerar dois falantes no mesmo clipe CRUZA as vozes. Solução conhecida: 1 clipe por falante, mesmo frame-âncora, voz única por geração — só com essa disciplina o formato passa |
| **Notícia estática / Oferta direta estática / Story estático** | versões estáticas seguram muito menos que com voz; em conta que performa com narração, estático vira exceção de teste, nunca padrão |
| **Meme** | depende de referência cultural viva — IA não acerta o timing do humor e o resultado envelhece em dias |
| **UGC 1ª pessoa só-mãos** | mãos são o ponto mais fraco dos geradores: dedos deformados em close matam a credibilidade justamente no formato que é só mão |
| **Tela dividida (split permanente)** | split segura menos que fullscreen no mesmo roteiro (comprovado em teste A/B interno); usar split só onde o gancho não tem conteúdo visual próprio |
| **Fala-e-faz** | sincronizar narração com ação manual contínua é o cenário onde a IA mais derrapa (ação atrasa/adianta da fala) |
| **Palestrinha / Google Meet / Live** | UI de reunião e "ao vivo" esbarram em política de plataforma ("live" falso) e em telas com texto gerado errado |
| **Passo a passo / Receita** | tutoriais exigem CONTINUIDADE de objeto entre cenas — o objeto muda de forma entre clipes gerados; exige still-por-bloco rígido |
| **Copy no papel** | texto manuscrito legível é impossível de gerar consistente; a saída é papel ilegível de propósito — mas aí o formato perde a graça |
| **ASMR** | o valor é 100% do áudio real; TTS não entrega textura de som tátil |
| **Série (dia 1, 2...)** | exige consistência de personagem/cenário entre VÁRIOS vídeos — dobra o custo de controle de qualidade |
| **Edit (montagem em beat)** | dificuldade máxima de pós-produção; retorno não justificou na prática |
| **Rotina ("um dia comigo")** | muitas locações + mesma persona = a consistência de rosto/figurino quebra em algum clipe |
| **Leia a legenda** | a copy mora no caption e o vídeo é enfeite — funciona pra orgânico, fraco pra tráfego frio |

### Os erros de produção que viraram LEI (valem pra qualquer formato)
- **1 still por BLOCO narrativo + jump cuts** — nunca trocar cena no meio de uma fala.
- **Referência encadeada:** cada still novo gerado A PARTIR do anterior (senão rosto/figurino derivam).
- **Papel/documento escrito em cena = "FADED, ILLEGIBLE"** no prompt — gerador escreve texto errado e o close denuncia.
- **Cena sem pessoas = pedir "ABSOLUTELY NO PEOPLE"** explícito (o gerador adora enfiar figurantes).
- **Trava anti-texto na cena de CTA** — o gerador inventa letreiros.
- **Legendas por clipe com offset** — nunca uma legenda única pro vídeo inteiro (dessincroniza).
- **Trim de cabeça e cauda (+0,5s no fim)** em todo clipe gerado.
- **Zoom artificial em foto (zoompan) TREME** — usar still + crossfade; normalizar tudo pra 1080×1920.
- **Moldura de celular NUNCA aparece no criativo** (nem gerada, nem no enquadramento).
- **Fogo em cena = travar a chama no prompt** (vela parada; só a mão se move).
- **Palavras que contaminam a cena:** citar "banco" no prompt gera letreiro escrito errado; descrever o LUGAR ("rua comercial movimentada") em vez da instituição.
- **Frame 1 = impacto visual** que para o dedo — física real, proporção crível.
- **Roupa única + fundo travado por sessão** — um frame-âncora por persona/cenário, reusado na sessão inteira.
- **Conferir CONTEÚDO do que foi gerado/baixado, nunca só o tamanho do arquivo** — QA por transcrição de cada clipe + gate visual de frames antes da montagem.
