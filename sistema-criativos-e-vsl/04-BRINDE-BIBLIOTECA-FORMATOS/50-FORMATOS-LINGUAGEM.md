# 🎬 50 FORMATOS DE LINGUAGEM DE CRIATIVO — TABELA MESTRA

> **O que é isto:** o mapa das 50 "embalagens" de linguagem que o mercado de tráfego direto usa pra re-empacotar uma mensagem que já vende. São formatos de LINGUAGEM (como o vídeo fala com o espectador), diferentes dos formatos de ESTRUTURA da BIBLIOTECA-FORMATOS.md (a ordem dos argumentos). Os dois se combinam: uma mesma estrutura de censura pode ser embalada como UGC, como telejornal ou como corte de podcast.
>
> **Princípio nº1: copy validada entra, formato só re-embala.** Nunca crie mensagem nova junto com formato novo. Pegue a alavanca que já vende (da sua VSL, do seu criativo campeão, da oferta modelada) e re-encaixe na estrutura do formato. Um criativo testa UMA variável.
>
> **Legenda:** **Dif** = dificuldade de produção 1-5 · **UI** = precisa de overlay gráfico (caixinha, tweet, chat, manchete — todos recriáveis em HTML→PNG em minutos) · **Melhor pra** = onde o formato historicamente rende mais.

## NOTAS DE ADAPTAÇÃO POR PÚBLICO

- **Público 45+ (fé, nutra, saúde):** formatos de UI de rede social jovem (fofoca, tweet, TikTok) precisam de tradução cultural — a estética "página de fofoca" não existe igual pra esse público. A versão que funciona é **notícia/telejornal** (04/05/49) e **testemunho** (11/14/42). "Anjinho vs Diabinho" (50) é tematicamente perfeito pro nicho de fé (tentação literal).
- **Público jovem BR (feed nativo):** série com placar (39), rotina (41), react (10) e fofoca (09) são a linguagem nativa do feed.
- **Formatos com UI:** todos os overlays (caixinha, tweet, chat, manchete) são triviais de recriar em HTML→PNG e ficam idênticos aos nativos. Não dependa de template de terceiro.
- **Regra de dificuldade:** comece a operação pelos formatos Dif 1-2 SEM UI (07, 11, 34, 42, 23) — são os que a produção IA reproduz com menor taxa de refação. Os Dif 4-5 só depois que a esteira estiver rodando.
