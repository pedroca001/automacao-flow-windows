# 🔎 Swipe File — acesse online (sempre atualizado)

Seu swipe file **fica online e é atualizado pra você** — você não precisa abrir nenhum arquivo aqui na sua máquina.

## 👉 Acesse: **https://001class.site/swipefile/**

É um banco de **~800 ofertas escaladas** rodando agora na Facebook Ads Library, em vários nichos e idiomas. Abre direto no navegador, no celular ou no computador.

## Como usar

1. Abra o link.
2. Filtre por **estrutura** (VSL / página de vendas / quiz), **língua** (BR / ES / EN), **produto** e **país**.
3. O **termômetro de escala** mostra quantos anúncios ativos cada página tem rodando — quanto mais alto, mais a oferta está validada com dinheiro real.
4. Clique em **Ver Biblioteca** pra abrir a Ad Library daquela página e estudar os criativos de verdade.
5. Favorite (❤) as ofertas que você quer modelar.

## O que os números significam

- **🔥 X ativos** = anúncios ativos hoje. Muitos anúncios rodando há semanas = a oferta está escalando com lucro.
- **↑ / ↓ delta** = variação desde a última checagem. Subindo = escalando.
- **Estrutura** = o tipo de funil que a oferta usa pra converter.

## Regra de ouro

**Nunca crie um criativo ou uma VSL sem antes olhar aqui.** Você não busca uma ideia — você busca dinheiro que já está circulando. Ache o que está vendendo, e o sistema modela pra você.

> Quer montar o **seu próprio** swipe file, com os nichos que você escolher? O sistema faz isso via o módulo de espionagem — veja `01-CRIATIVOS/01-ESPIONAGEM-APIFY.md`. Peça pro seu Claude: *"garimpa as ofertas escaladas do nicho X na Ad Library e monta meu swipe file."*
